# 大模型训练场 · Training Lab

[开始游戏](https://hacking.pub/games/training-lab/) · [English](README.md) · [神经工坊](https://hacking.pub/games/neural-atelier/)

小车能回答三个命令：停车 HOLD、前进 GO 和检查 CHECK。每点一次「训练一步」，浏览器就按你给的训练信号更新三个分数，再把新概率画出来。黑色刻度记录上一步更新前的位置。

五个实验可以逐关玩，也可以直接打开其中一关：

1. **预训练**。把不同结尾的日志放进语料，观察下一个 token 的概率。
2. **SFT**。给“停车，只用一个命令作答”选一份示范回答。
3. **DPO**。给同一条指令选出更喜欢和更不喜欢的两个回答，观察相对参考策略的概率比。
4. **RL / REINFORCE**。先给最短回答打高分，再给正确回答打高分，比较小车更爱说什么。
5. **GRPO**。对同一道题采样八份回答，先让它们同分，再制造组内分差，观察优势和模型更新。

后训练中的三种分支可分别取 SFT 的通关点作为起点。模型为单个上下文训练三个分数，回答长度为一个 token。教学模型用这个尺寸把梯度、概率和 KL 摊开给你看。关卡中的“怎么更新”和训练手册里有到 nanoGPT、verl 和论文的对应入口。

本地运行：在仓库目录执行 `python3 -m http.server 8000 --bind 127.0.0.1`，打开 [本地游戏](http://127.0.0.1:8000)。运行测试：`node --test tests/*.test.mjs`（Node.js 20+）。本站默认英文，右上角可切中文，进度保存在当前浏览器。
